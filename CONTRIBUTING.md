# CONTRIBUTING.md

# Contributing to ADMFL

Thank you for contributing to ADMFL.

We welcome:

- bug fixes
- new FL algorithms
- SDN enhancements
- P4 improvements
- attack simulation modules
- optimization techniques
- evaluation improvements

---

# Contribution Workflow

## 1. Fork Repository

Create your own fork of ADMFL.

---

## 2. Clone Repository

```bash
git clone https://github.com/your-username/ADMFL.git
```

---

## 3. Create New Branch

```bash
git checkout -b feature/new-feature
```

---

## 4. Make Changes

Implement your changes and ensure:

- clean code
- proper logging
- documentation updates
- testing support

---

## 5. Run Tests

```bash
pytest tests/
```

---

## 6. Commit Changes

```bash
git commit -m "Added new feature"
```

---

## 7. Push Changes

```bash
git push origin feature/new-feature
```

---

## 8. Open Pull Request

Submit a pull request with:

- feature description
- motivation
- implementation details
- experimental results if applicable

---

# Coding Guidelines

- Follow PEP8 style
- Use descriptive variable names
- Add logging for major operations
- Document functions and classes
- Keep modules modular

---

# Reporting Issues

Please include:

- operating system
- Python version
- error logs
- reproduction steps

---
